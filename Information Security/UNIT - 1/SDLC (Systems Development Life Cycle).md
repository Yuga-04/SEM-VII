# SDLC (Systems Development Life Cycle) – 13 Marks

## Introduction

**SDLC (Systems Development Life Cycle)** is a **methodology for the design and implementation of an information system in an organization**.

A methodology is a **formal approach to solving a problem based on a structured sequence of procedures**. Using a methodology ensures a rigorous process and avoids missing steps that could compromise the final goal.

The goal of SDLC is to create a **comprehensive security posture**, and it also increases the probability of success. Once a methodology is adopted, key milestones are established and a team of individuals is made accountable for achieving the project goals. a0978e71-136b-470e-8889-ed245dd…

## SDLC Waterfall Methodology

The traditional SDLC follows the **Waterfall model**. It consists of **six general phases**.

```text
                SDLC
                  │
     ┌────────────┴────────────┐
     │                         │
Investigation                Analysis
     │                         │
     ▼                         ▼
Logical Design ───────► Physical Design
                              │
                              ▼
                       Implementation
                              │
                              ▼
                    Maintenance & Change
```

Each phase begins with the **results and information gained from the previous phase**. a0978e71-136b-470e-8889-ed245dd…

The six phases are:

1. Investigation
2. Analysis
3. Logical Design
4. Physical Design
5. Implementation
6. Maintenance and Change

---

# 1. Investigation

The **Investigation phase** begins with an examination of the **event or plan that initiates the process**.

During this phase:

- The **objectives** of the project are specified.
- The **constraints** are identified.
- The **scope** of the project is defined.
- A preliminary **cost-benefit analysis** is developed.
- A feasibility analysis is performed. a0978e71-136b-470e-8889-ed245dd…

The feasibility analysis assesses:

- **Economic feasibility**
- **Technical feasibility**
- **Behavioral feasibility**

It ensures that implementation is worth the organization's **time and effort**. a0978e71-136b-470e-8889-ed245dd…

---

# 2. Analysis

The **Analysis phase** begins with the information obtained during the Investigation phase.

This phase primarily involves:

- Assessment of the organization.
- Assessment of the status of current systems.
- Assessment of the capability to support the proposed systems.

Analysts determine:

- **What the new system is expected to do.**
- **How it will interact with existing systems.**

The phase ends with documentation of the findings and an **update of the feasibility analysis**. a0978e71-136b-470e-8889-ed245dd…

---

# 3. Logical Design

The information obtained from the Analysis phase is used to create a **solution system for the business problem**.

The first and driving factor in a systems solution is the **business need**.

The logical design process involves:

1. Identifying the business need.
2. Selecting applications capable of providing the required services.
3. Selecting data support and structures required for the inputs.
4. Identifying the technologies required to implement the physical solution.

The **logical design is the blueprint for the desired solution**. a0978e71-136b-470e-8889-ed245dd…

An important point is that logical design is **implementation independent**. This means it contains no reference to specific:

- Technologies
- Vendors
- Products

---

# 4. Physical Design

In the **Physical Design phase**, specific technologies are selected to support the alternatives identified and evaluated during logical design.

The process includes:

- Selecting specific technologies.
- Evaluating the selected components.
- Making a **make-or-buy decision**.
- Integrating various components and technologies.
- Conducting another feasibility analysis.
- Presenting the complete solution to organizational management for approval. a0978e71-136b-470e-8889-ed245dd…

Thus, physical design converts the logical blueprint into a specific technological solution.

---

# 5. Implementation

In the **Implementation phase**:

- Required software is created.
- Components are ordered.
- Components are received and tested.
- Users are trained.
- Supporting documentation is created.
- Individual components are tested.
- Components are installed and tested as a complete system. a0978e71-136b-470e-8889-ed245dd…

A further feasibility analysis is prepared.

Finally, the system is presented to the sponsors for:

- **Performance review**
- **Acceptance testing**

---

# 6. Maintenance and Change

The **Maintenance and Change phase** is the **longest and most expensive phase** of the SDLC process.

It consists of the tasks necessary to:

- Support the system.
- Modify the system.
- Maintain the system for the remainder of its useful life cycle. a0978e71-136b-470e-8889-ed245dd…

At periodic points:

- The system is tested for compliance.
- The feasibility of continuing or discontinuing the system is evaluated.
- Upgrades are managed.
- Updates are managed.
- Patches are managed.

As the organization's needs change, the systems supporting the organization must also change.

When the current system can no longer support the evolving mission of the organization, the project is terminated and a **new project begins from the Investigation phase**. a0978e71-136b-470e-8889-ed245dd…

# SDLC Phase Summary

| Phase | Main Activities |
|---|---|
| **Investigation** | Define problem, objectives, constraints, scope, cost-benefit and feasibility |
| **Analysis** | Assess organization and existing systems; determine system requirements |
| **Logical Design** | Develop the blueprint and identify applications, data structures and required solution |
| **Physical Design** | Select specific technologies and integrate components |
| **Implementation** | Create/acquire, test and install the system; train users |
| **Maintenance & Change** | Support, modify, test, upgrade, update and patch the system |

## Conclusion

The **Systems Development Life Cycle (SDLC)** provides a **structured methodology** for designing and implementing an information system.

The traditional Waterfall SDLC consists of six phases:

**Investigation → Analysis → Logical Design → Physical Design → Implementation → Maintenance & Change**

Each phase uses the results of the previous phase. This structured approach helps ensure that important steps are not missed and increases the probability of successfully developing and maintaining the information system. a0978e71-136b-470e-8889-ed245dd…
