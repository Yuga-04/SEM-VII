# NSTISSC Security Model and Top-Down Approach to Security

## 1. NSTISSC Security Model

The **NSTISSC Security Model** is based in part on the *National Training Standard for Information Security Professionals (NSTISSI No. 4011)*, developed in connection with the **National Security Telecommunications and Information Systems Security Committee (NSTISSC)**.

The document presents a **comprehensive model for information security** and is becoming an evaluation standard for the security of information systems. a0978e71-136b-470e-8889-ed245dd…

### Three dimensions of the NSTISSC Security Model

The model consists of **three dimensions**:

1. **Information characteristics**
   - Confidentiality
   - Integrity
   - Availability

2. **Information states**
   - Storage
   - Processing
   - Transmission

3. **Security measures**
   - Policy
   - Education
   - Technology

These three dimensions form a **3 × 3 × 3 cube**, giving **27 cells**. Each cell represents an area that must be addressed to secure a modern information system. a0978e71-136b-470e-8889-ed245dd…

### Functions of the NSTISSC Security Model

**1. Ensures Confidentiality**

Confidentiality prevents disclosure or exposure of information to unauthorized individuals or systems. It ensures that only users having the required rights and privileges can access the information. a0978e71-136b-470e-8889-ed245dd…

**2. Ensures Integrity**

Integrity means that information remains whole, complete and uncorrupted. The model ensures that appropriate controls are used to protect information from corruption, damage, destruction or other disruption. a0978e71-136b-470e-8889-ed245dd…

**3. Ensures Availability**

Availability ensures that authorized users can access information **when and where it is needed and in the correct format**. a0978e71-136b-470e-8889-ed245dd…

**4. Protects information in different states**

Security must be considered while information is:
- **Stored**
- **Processed**
- **Transmitted**

Thus, the model does not restrict security to only one stage of information handling. a0978e71-136b-470e-8889-ed245dd…

**5. Uses policy, education and technology**

The model considers:
- **Policy** – provides direction for security practices.
- **Education** – helps users understand and follow security requirements.
- **Technology** – provides technical controls and safeguards.

**6. Provides 27 areas for security coverage**

The main responsibility is to make sure that **all 27 cells** of the cube are properly addressed during the security process. a0978e71-136b-470e-8889-ed245dd…
