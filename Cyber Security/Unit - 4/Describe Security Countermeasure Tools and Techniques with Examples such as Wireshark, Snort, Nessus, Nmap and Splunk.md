## Introduction

Security countermeasures are **strategies, tools and techniques used to protect information systems from cyber threats and attacks**. They may be **preventive, detective or corrective** in nature. 94edd808-a76b-4a61-9168-b09ccf8…

## 1. Wireshark

**Wireshark** is a network protocol analysis tool used to **capture and examine network traffic**.

### Functions:
- Captures network packets.
- Helps analyze network protocols.
- Helps identify unusual or suspicious network activity.
- Useful for troubleshooting network problems.

**Example:** A security administrator can analyze captured packets to identify suspicious communication in a network.

> **Remember:** Wireshark → **Packet/Traffic Analysis**

---

## 2. Snort

**Snort** is an **Intrusion Detection System (IDS)** used to monitor network traffic for malicious activities.

### Functions:
- Monitors network traffic.
- Detects suspicious or malicious activities.
- Generates alerts when potential attacks are detected.

**Example:** Snort can detect suspicious network traffic that may indicate an intrusion.

The PDF identifies **Snort IDS** as an example of an intrusion detection system. 94edd808-a76b-4a61-9168-b09ccf8…

> **Remember:** Snort → **Intrusion Detection**

## 3. Nessus

**Nessus** is a **vulnerability scanning tool** used to identify weaknesses in systems and applications.

### Functions:
- Scans systems for vulnerabilities.
- Identifies outdated software.
- Helps detect security weaknesses.
- Helps administrators fix vulnerabilities before attackers exploit them.

**Example:** Nessus can identify an unpatched application that contains a known security vulnerability.

The PDF lists **Nessus and OpenVAS** as vulnerability scanners. 94edd808-a76b-4a61-9168-b09ccf8…

> **Remember:** Nessus → **Vulnerability Scanning**

---

## 4. Nmap

**Nmap (Network Mapper)** is a network scanning tool used to discover hosts, services and open ports in a network.

### Functions:
- Discovers devices on a network.
- Identifies open ports.
- Helps identify running services.
- Supports network security assessment.

**Example:** A security administrator can use Nmap to identify unnecessary open ports on organizational servers.

> **Remember:** Nmap → **Network/Port Scanning**

---

## 5. Splunk

**Splunk** is a **Security Information and Event Management (SIEM)** platform used for security monitoring and log analysis.

### Functions:
- Collects logs from different systems.
- Correlates security events.
- Monitors activities in real time.
- Generates alerts for suspicious events.

**Example:** Splunk can collect login and firewall logs and help identify unusual login activity.

The PDF specifically gives **Splunk and IBM QRadar** as examples of SIEM platforms. 94edd808-a76b-4a61-9168-b09ccf8…

> **Remember:** Splunk → **Log Monitoring / SIEM**

# 6. Other Security Countermeasure Techniques

### a) Firewalls
Monitor and filter incoming and outgoing traffic according to security rules. 94edd808-a76b-4a61-9168-b09ccf8…

### b) Antivirus and Anti-malware
Detect, prevent and remove malicious software such as viruses, worms, Trojans and ransomware. 94edd808-a76b-4a61-9168-b09ccf8…

### c) IDS/IPS
- **IDS:** Detects suspicious activities and generates alerts.
- **IPS:** Detects and prevents potential threats in real time. 94edd808-a76b-4a61-9168-b09ccf8…

### d) Access Control
Ensures that only authorized users can access resources.

Types include:
- **DAC** – Discretionary Access Control
- **MAC** – Mandatory Access Control
- **RBAC** – Role-Based Access Control 94edd808-a76b-4a61-9168-b09ccf8…

### e) Security Hardening
Reduces system vulnerabilities by:
- Disabling unnecessary services.
- Applying patches and updates.
- Using strong password policies.
- Encrypting sensitive data. 94edd808-a76b-4a61-9168-b09ccf8…

### Conclusion

Security countermeasure tools help organizations **detect, prevent and respond to cyber threats**. Tools such as **Wireshark, Snort, Nessus, Nmap and Splunk** support different security activities including **traffic analysis, intrusion detection, vulnerability scanning, network scanning and security monitoring**. When combined with firewalls, antivirus, access control and hardening techniques, they provide effective protection for organizational systems and networks.
