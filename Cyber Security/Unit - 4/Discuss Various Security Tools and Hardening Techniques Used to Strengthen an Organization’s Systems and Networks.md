## 1. Network Security Tools

### a) Firewalls
Firewalls control and filter traffic entering or leaving a network. They block unauthorized access based on security rules.

**Function:** Protect the internal network from untrusted external networks.

### b) IDS/IPS
- **IDS (Intrusion Detection System):** Monitors network traffic for suspicious activity and generates alerts.
- **IPS (Intrusion Prevention System):** Detects and automatically blocks malicious activity. 94edd808-a76b-4a61-9168-b09ccf8…

### c) VPN
A **Virtual Private Network (VPN)** creates an encrypted tunnel for secure communication over public networks. 94edd808-a76b-4a61-9168-b09ccf8…

## 2. Endpoint or Host Security Tools

### a) Anti-virus and Anti-malware
These tools scan files and processes to detect, quarantine and remove malicious programs.

### b) Host-Based Firewall
Provides an additional layer of traffic filtering directly on individual computers.

### c) Endpoint Detection and Response (EDR)

## 3. Data Security Tools

### a) Encryption
Encryption makes data unreadable without the correct key. It protects data **at rest and in transit**.

**Examples:** BitLocker and VeraCrypt.

### b) Data Loss Prevention (DLP)

# Hardening Techniques

System hardening reduces vulnerabilities by securely configuring systems and reducing unnecessary attack points.

## 5. Patch Management

Regularly update:

- Operating systems
- Applications
- Firmware

## 6. Disable Unnecessary Services and Ports

Turn off services, daemons and open ports that are not required.

**Benefit:** Reduces possible entry points for attackers. 94edd808-a76b-4a61-9168-b09ccf8…

## 7. Strong Authentication and Access Control

Organizations should use:

- Strong passwords
- Multi-Factor Authentication (MFA)
- Principle of least privilege

## 9. Encryption of Data

Sensitive data should be encrypted:

- **At rest** – while stored on devices.
- **In transit** – while travelling across networks.

## 10. Regular Backups and Recovery Planning

Organizations should:

- Maintain scheduled backups.
- Store backups securely.
- Test restoration procedures.

This helps recover quickly from **ransomware attacks or hardware failures**. 94edd808-a76b-4a61-9168-b09ccf8…

## 11. Logging and Continuous Monitoring

Detailed logs should be enabled for critical services and continuously monitored.

This helps organizations **detect suspicious activities early**. 94edd808-a76b-4a61-9168-b09ccf8…

---

## Conclusion

Organizations can strengthen their systems and networks by combining **security tools** such as firewalls, IDS/IPS, VPNs, antivirus, EDR, encryption, DLP, SIEM and vulnerability scanners with **hardening techniques** such as patch management, disabling unnecessary services, strong authentication, secure configuration, backups and continuous monitoring.

Thus, a combination of security tools and system hardening provides **multi-layered protection and reduces the organization's attack surface**.
